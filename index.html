📘 Guía: ¿qué variables puedo modificar?

Iteraciones máximas (30–600): cantidad máxima de veces que se calcula la ecuación. Más iteraciones pueden detectar escapes tardíos.

Zoom (1×–12×): amplía una región del plano complejo. Puedes desplazar el centro para ver otras zonas.

Centro real y centro imaginario: permiten desplazar horizontal y verticalmente la región del fractal que se observa.

Paleta: modifica los colores, pero no los cálculos matemáticos.

Re(c) e Im(c): determinan el número complejo c = a + bi. Se mantiene constante durante una órbita.

Re(z₀) e Im(z₀): determinan el valor inicial de la sucesión. Para analizar el conjunto de Mandelbrot se utiliza z₀ = 0.

Cómo utilizar el simulador: pulsa Iniciar para crear el fractal. Después introduce valores de c y z₀ y selecciona Calcular si escapa. Observa la tabla y las gráficas.

Al cambiar el zoom: se calcula una nueva vista conservando la imagen anterior durante el cálculo. Una región uniforme no significa necesariamente que se haya perdido el fractal.

Nota: no detectar escape en un número finito de iteraciones no prueba pertenencia al conjunto.

FUNDAMENTO MATEMÁTICO · GEOMETRÍA FRACTAL

¿Cómo se genera y se interpreta el conjunto de Mandelbrot?

El conjunto de Mandelbrot está formado por los parámetros complejos c para los cuales la sucesión iniciada en z₀ = 0 permanece acotada. Se utiliza la siguiente ecuación:

zₙ₊₁ = zₙ² + c c = a + bi · zₙ = xₙ + yₙi · i² = −1

1 · Parte real

xₙ₊₁ = xₙ² − yₙ² + a

Se calcula desarrollando el cuadrado del número complejo.

2 · Parte imaginaria

yₙ₊₁ = 2xₙyₙ + b

Describe el cambio del componente imaginario.

3 · Módulo

|zₙ| = √(xₙ² + yₙ²)

Expresa la distancia de zₙ respecto al origen.

4 · Criterio de escape

|zₙ| > 2

Para z₀ = 0, superar el valor 2 demuestra el escape.

Importante: si no se detecta escape durante 180 o 600 iteraciones, esto no demuestra que el punto pertenezca al conjunto de Mandelbrot.

Interpretación de las gráficas

Gráfica 1: representa numerosos valores de c en el plano complejo. Los colores reflejan cuándo escapan. Gráfica 2: muestra la evolución de las partes real e imaginaria de zₙ. Gráfica 3: representa el módulo de zₙ. La tabla muestra los cálculos de cada iteración.

Cuando se modifica c, cambia la sucesión. Cuando se modifica z₀, cambia su valor inicial. Para determinar la pertenencia de c al conjunto de Mandelbrot debe mantenerse z₀ = 0.

c = 0, z₀ = 0 0 → 0 → 0 → 0… Órbita fija y acotada.
c = −1, z₀ = 0 0 → −1 → 0 → −1… Ciclo periódico de longitud 2.
c = 1, z₀ = 0 0 → 1 → 2 → 5… Escape en la iteración 3.
