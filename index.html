FUNDAMENTO MATEMÁTICO · GEOMETRÍA FRACTAL

¿Cómo se genera e interpreta el conjunto de Mandelbrot?

El conjunto de Mandelbrot reúne los parámetros complejos c para los que la órbita iniciada en z₀ = 0 permanece acotada al aplicar repetidamente una transformación cuadrática.

zₙ₊₁ = zₙ² + c c = a + bi · zₙ = xₙ + yₙi · i² = −1

1 · Parte real

xₙ₊₁ = xₙ² − yₙ² + a

Se obtiene desarrollando el cuadrado del número complejo.

2 · Parte imaginaria

yₙ₊₁ = 2xₙyₙ + b

Describe la evolución del coeficiente imaginario.

3 · Módulo

|zₙ| = √(xₙ² + yₙ²)

Es la distancia al origen en el plano complejo.

4 · Criterio de escape

|zₙ| > 2

Para z₀ = 0, superar este umbral demuestra que c está fuera del conjunto.

Importante: que no se detecte escape durante 180 o 600 iteraciones no demuestra que el punto pertenezca al conjunto de Mandelbrot.

Interpretación de las gráficas y controles

Gráfica 1: cada píxel representa un valor diferente de c. Sus colores reflejan las iteraciones necesarias para detectar escape. El zoom permite explorar detalles del fractal y las coordenadas cambian la región observada.

Gráfica 2: representa la evolución de las partes real e imaginaria. Gráfica 3: representa el módulo y el umbral de escape. Tabla: muestra los valores de cada iteración y permite comprobar los cálculos.

¿Qué ocurre al cambiar c o z₀? El valor c se mantiene constante durante cada cálculo, mientras que z cambia en cada iteración. Si z₀ es diferente de cero, se estudia una órbita de la función z² + c, no la pertenencia directa de c al conjunto.

c = 0, z₀ = 0 0 → 0 → 0 → 0… Órbita fija y acotada
c = −1, z₀ = 0 0 → −1 → 0 → −1… Ciclo periódico de longitud 2
c = 1, z₀ = 0 0 → 1 → 2 → 5… Escape en la iteración 3
