FUNDAMENTO MATEMÁTICO · GEOMETRÍA FRACTAL

¿Cómo se genera y se interpreta el conjunto de Mandelbrot?

El conjunto de Mandelbrot es el conjunto de parámetros complejos c para los que la órbita iniciada en z₀ = 0 permanece acotada al repetir la transformación cuadrática siguiente:

zₙ₊₁ = zₙ² + cc = a + bi · zₙ = xₙ + yₙi · i² = −1

1 · Parte real

xₙ₊₁ = xₙ² − yₙ² + a

Se obtiene al desarrollar el cuadrado del número complejo y sumar la parte real de c.

2 · Parte imaginaria

yₙ₊₁ = 2xₙyₙ + b

Describe cómo cambia el coeficiente imaginario en cada iteración.

3 · Módulo de zₙ

|zₙ| = √(xₙ² + yₙ²)

Es la distancia de zₙ al origen del plano complejo y se representa en la gráfica 3.

4 · Criterio de escape

|zₙ| > 2

Con z₀ = 0, superar 2 en cualquier iteración demuestra que c está fuera del conjunto. La igualdad con 2 no es escape.

Importante: si un punto no supera el radio de escape durante 180 o 600 iteraciones, el simulador solo informa «escape no detectado»; no demuestra matemáticamente que ese punto pertenezca al conjunto.

Cómo interpretar los controles y las gráficas

Gráfica 1 · Fractal: cada píxel es un valor distinto de c, calculado con z₀ = 0. Los colores representan el número de iteraciones antes de detectar escape; el área oscura corresponde a puntos sin escape detectado en el límite elegido. El zoom y el centro real/imaginario cambian la zona del plano que se muestra, mientras que las iteraciones cambian el detalle de la clasificación aproximada.

Gráfica 2 · Componentes de la órbita: muestra Re(zₙ) e Im(zₙ) conforme avanza n. Gráfica 3 · Módulo: muestra |zₙ| y el umbral de escape. Tabla: permite verificar cada valor numérico de la ecuación y el paso en que ocurrió el escape.

¿Qué sucede al cambiar c o z₀? El parámetro c permanece fijo durante cada cálculo, pero altera toda la sucesión. Al cambiar z₀ se modifica el punto inicial de la órbita: es un experimento válido sobre la dinámica de z² + c, pero ya no determina por sí mismo la pertenencia de c al conjunto de Mandelbrot. Para un z₀ personalizado, el laboratorio utiliza un umbral de escape suficiente, que puede ser mayor que 2.

c = −1, z₀ = 00 → −1 → 0 → −1 …Ciclo periódico de longitud 2
c = 1, z₀ = 00 → 1 → 2 → 5 …Escapa en n = 3
